# Враги и боссы

Настройки находятся в `src/enemies.json`.

- `appearance`: общий цвет тела и глаз.
- `profiles`: общие характеристики обычных врагов (`animal`) и боссов (`boss`).
- `enemies`: типы врагов. `id` уникален, `model` выбирает модель, `profile` — базовые параметры, `stats` переопределяет параметры профиля.
- `spiral`: размещение на лестнице. `afterSection` — нижняя граница номера секции, `everySections` и `offset` задают повторение, `cycle` — порядок типов.
- `arenas.bossCycle`: порядок боссов по этажам. На каждой арене один босс.
- `arenas.spawnInset`: отступ места появления босса от края арены в метрах.

У босса можно менять HP и рост HP по этажам, скорость преследования и рывка, интервалы атак, урон, размеры зоны контакта, появление из пола и очки за награду. `spawnDuration` задаёт секунды, `spawnDepth` — глубину под полом. У обычных врагов доступны высота и частота подскоков, слежение за игроком, HP и коллизии. Размеры и скорости указаны в мировых единицах, интервалы — в секундах.

Например, новый тип с существующей моделью:

```json
{
  "id": "swiftWolf",
  "name": "Быстрый волк",
  "model": "wolf",
  "profile": "animal",
  "stats": { "hp": 2, "trackRate": 2.4, "hopSpeed": 3.2 }
}
```

Добавьте его `id` в `spiral.cycle`, чтобы он появился в забеге. Доступные модели: `cat`, `wolf`, `fox`, `hare`, `reaper`. Новая геометрия и новый алгоритм поведения требуют изменений в коде; параметры и размещение меняются в JSON. Для босса используйте профиль `boss`, для обычного врага — `animal`.
