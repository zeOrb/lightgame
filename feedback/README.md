# Локальная доска Sunny

Запуск: `launchers/feedback-sunny.bat` или `npm run feedback`. Адрес: http://127.0.0.1:5174/. Игра и её сервер для работы доски не нужны; достаточно уже установленного Node.js. Дополнительных пакетов нет.

Во вкладке «Баги» находятся ошибки, во вкладке «Фидбек» — отзывы и предложения. Статусы: новое, в работе, на проверке, закрыто. Нажатие на карточку открывает редактор. Доступны поиск, фильтр статуса и выгрузка JSON.

Данные создаются при первом запуске в `feedback/data/cards.json`. Рядом находится копия предыдущего сохранения `cards.json.backup`. Для переноса или резервирования скопируй всю папку `feedback/data`. Рабочие записи исключены из Git, чтобы личный фидбек случайно не попал в публичный репозиторий. Доска доступна только с этого компьютера.

При одновременном редактировании одной карточки в нескольких вкладках устаревшая версия не перезаписывает новую: обнови список и открой карточку заново.

Для работы агента можно указать ID карточки или автора и текст — исходный JSON находится непосредственно в проекте. Приложение не отправляет сообщения авторам и не меняет статусы автоматически.
