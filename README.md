# Солнечный зайчик — Башня последнего света

Небольшая законченная 3D-игра на Three.js: последний блик заката спускается по спиральным полкам магической башни, чтобы сохранить свет в кристалле.

## Запуск

Нужен Node.js 22.12+.

```sh
npm ci
npm run dev
```

Открыть адрес из терминала. Для production: `npm run build`, затем `npm run preview`. Папка `dist` содержит весь сайт. Открытие HTML через `file://` не поддерживается: нужен HTTP-сервер.

## Управление

- **D / →** — спускаться по спирали; **A / ←** — возвращаться наверх.
- **W / ↑** — к внешнему краю; **S / ↓** — к внутреннему.
- **Пробел** — прыжок. **Esc** — пауза.
- На сенсорном экране — экранные кнопки; можно удерживать движение и одновременно прыгать.

В башне 12 этажей: от светлого 12-го до тёмного 1-го. Свет заката постепенно ослабевает по мере спуска. Яркость зайчика — его здоровье. Тени, лапы охотящихся котов и падающие книги забирают свет. Прыжок помогает избежать контакта. Провал отнимает 14 света и возвращает на последнюю безопасную позицию. Золотые блики восстанавливают 22 света. Цветные витражные мозаики на полках восстанавливают 1,92 HP/с, пока зайчик находится в свете. Пассивная потеря 0,96 HP/с и теневой урон продолжаются; защиты от урона нет. Все окна направляют сказочные лучи внутрь башни; мозаики сохраняются после прохода зайчика. Склянки на время отражают управление или замедляют. При нуле света — поражение; достижение кристалла запускает ночной финал. На паузе и в скрытой вкладке игра останавливается.

## GitHub Pages

1. Загрузить файлы проекта в репозиторий, включая `package-lock.json` и `.github/workflows/deploy.yml`.
2. Основная ветка — `main`. Для другой ветки поменять `on.push.branches` в workflow.
3. В **Settings → Pages → Source** выбрать **GitHub Actions**.
4. Сделать push в `main` или запустить workflow вручную во вкладке Actions.

Workflow проверяет игровую математику, собирает и публикует `dist`. `base: './'` позволяет запускать сборку как в корне домена, так и по адресу `username.github.io/repository/`. Зависимости включаются в сборку; внешние CDN, шрифты, картинки, API и сервер не требуются. Звук создаётся Web Audio после включения пользователем. Требуется браузер с WebGL 2 и аппаратным ускорением.

## Этапы реализации

- [x] Спиральный маршрут, камера, движение, прыжок и запас света.
- [x] Тени, блики, витражное восстановление, зверьё, склянки, падающие книги, провалы.
- [x] Круглая башня, геометрические книжные стеллажи, витражи, ловец солнца, частицы и финальный кристалл.
- [x] Пауза, перезапуск, сенсорные кнопки, звук и статическая сборка для GitHub Pages.

Все модели и эффекты генерируются кодом. Маршрут — 12 этажей по 14 секций на шести витках спирали (168 секций). Четыре вида теневых зверей: кошка, волк, лиса и заяц. При приземлении на спину зверь растворяется снизу вверх с вертикальным чёрным дымом; зайчик отскакивает. Касание сбоку наносит теневой урон. Расчёт теней игровой, без физической трассировки лучей. Солнечный зайчик после рождения движется магически.

`npm test` проверяет маршрут, провалы и расход света. Для ручной проверки: пройти провал прыжком, собрать блик, проверить восстановление под витражом и урон без иммунитета, коснуться склянки, проверить паузу и перезапуск после обоих финалов.

## Угрозы

Типы угроз и их поведение описаны в src/threats.js: hole (провал) и moving-platform (сдвигающаяся полка). Подвижная полка каждые 5 секунд предупреждает о движении, уходит внутрь башни на 2,1 единицы и возвращается. Внешний край может уйти из-под зайчика: помогает прыжок или переход к внутреннему краю. При настоящем падении теряется 14 HP; полка не наносит урон в воздухе. Витражные зоны на подвижных полках не размещаются.

Дополнительные типы используют тот же реестр, общий сброс и независимые проверки попаданий. Их модели и предупреждения находятся в `src/threat-visuals.js`:

- `pendulum` — колокол затмения, качается поперёк полки с периодом 3,6 секунды. Потеря 10 света при столкновении с самим колоколом; можно обойти по свободной стороне. Красный камень и метка под колоколом показывают его положение.
- `ink-wave` — чернильница выпускает расширяющееся кольцо раз в 5,2 секунды. Перед выбросом светится руна; волна снимает 8 света у земли, прыжок выше 0,62 единицы безопасен.
- `thorns` — стеклянные шипы на половине полки. Цикл 4,8 секунды, перед выдвижением руны мигают 0,8 секунды. Потеря 12 света; можно обойти по другой стороне или перепрыгнуть.

Новые угрозы расставлены несколькими экземплярами от верхних к нижним этажам, отдельно от провалов, подвижных полок, зверей, книг, склянок и бликов. Между угрозами минимум три секции; витражные проекции на их полки не назначаются. Повторное попадание одной угрозой возможно не чаще чем раз в 1,15 секунды. Пауза останавливает циклы, перезапуск сбрасывает фазу и историю попаданий. Тесты проверяют размещение, реальные зоны столкновения, обход, прыжки, предупреждения и сброс.
