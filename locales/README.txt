Локализация Sunny

ru.po — русский; en.po — английский. Открывайте в Poedit, Lokalize или другом
редакторе GNU gettext. Редактируйте msgstr; msgid, msgctxt и {параметры} сохраняйте.
messages.pot — общий шаблон. Для старых ключей настроек msgctxt хранит стабильный
ключ; у игровых текстов msgid — исходная русская фраза. Контентные JSON хранят
исходные названия и описания; перевод выбирается только при отображении.

npm run locales:update — собрать новые строки из интерфейса и контентных JSON,
обновить шаблон и оба PO, сохранив существующие переводы.
npm run locales:compile — проверить каталоги и подготовить данные игры.
При запуске Vite и сборке подготовка выполняется автоматически. Изменения PO
во время разработки обновляют игру. В Windows/Electron используется тот же набор.
src/locales.generated.json создаётся автоматически; вручную его не редактировать.

Непереведённые или fuzzy-записи используют русский вариант. Синтаксические ошибки,
повторяющиеся ключи и потерянные {параметры} останавливают сборку с указанием ошибки.
Текущий интерфейс использует целые фразы с параметрами, без выбора падежа по числу.
msgid_plural требует отдельного plural-aware вызова и пока явно отклоняется.

При добавлении новых игровых строк используйте tr('Русский исходный текст',
{parameter: value}); предложение целиком, без склеивания переводимых фрагментов.
Статическая разметка: data-i18n="Русский исходный текст"; для атрибутов:
data-i18n-aria-label, data-i18n-title, data-i18n-content.
