Локализация Sunny

ru/ — русский; en/ — английский; templates/ — шаблоны POT.
В каждой папке пять категорий:
  buttons — кнопки, действия и заголовки меню;
  settings — параметры настроек и управление;
  skills — навыки: название, сразу за ним описание;
  gameplay — HUD, игровые сообщения, предметы и диагностика уровня;
  bestiary — названия врагов и характеристики бестиария.

Например, для описаний навыков откройте ru/skills.po в Poedit,
Lokalize или другом редакторе GNU gettext. Редактируйте msgstr;
msgid, msgctxt и {параметры} сохраняйте. Для старых ключей настроек msgctxt хранит стабильный
ключ; у игровых текстов msgid — исходная английская фраза. Контентные JSON хранят
исходные названия и описания; перевод выбирается только при отображении.

npm run locales:update — собрать новые строки из интерфейса и контентных JSON,
обновить шаблоны и PO обоих языков, сохранив существующие переводы.
Категории назначаются автоматически при обновлении. Один ключ хранится только
в одном файле, даже если фраза используется в нескольких местах интерфейса.
npm run locales:compile — проверить каталоги и подготовить данные игры.
При запуске Vite и сборке подготовка выполняется автоматически. Изменения PO
во время разработки обновляют игру. В Windows/Electron используется тот же набор.
src/locales.generated.json создаётся автоматически; вручную его не редактировать.

Непереведённые или fuzzy-записи используют английский источник. Синтаксические ошибки,
повторяющиеся ключи и потерянные {параметры} останавливают сборку с указанием ошибки.
Текущий интерфейс использует целые фразы с параметрами, без выбора падежа по числу.
msgid_plural требует отдельного plural-aware вызова и пока явно отклоняется.

При добавлении новых игровых строк используйте tr('English source text',
{parameter: value}); предложение целиком, без склеивания переводимых фрагментов.
Статическая разметка: data-i18n="English source text"; для атрибутов:
data-i18n-aria-label, data-i18n-title, data-i18n-content.

В skills.po сохраняется порядок веток и навыков из конфигов. Название навыка
и его описание идут соседними записями. Если описание используется несколькими
навыками, дополнительная запись получает msgctxt skill.<id>.description,
чтобы пары сохранялись и при необходимости переводились независимо.

Исходный язык — английский во всех категориях: msgid содержит английскую
фразу, msgstr в ru/*.po — русский перевод. en/*.po повторяет источник,
а templates/*.pot хранит исходные фразы без перевода. Новые строки в коде
и контентных JSON добавляйте на английском. Язык интерфейса по умолчанию
по-прежнему русский.
