# Деревья поведения врагов

Конфигурация: `src/enemy-state-trees.json`. В `src/enemies.json` поле `stateTree` назначает дерево врагу. Сейчас `shadow-jump` назначено обычной Тени (`wolf`) на спиральной лестнице. Враги без этого поля сохраняют прежнее поведение; логика боссов на аренах остаётся в системе арен.

Узлы:

- `sequence`, `children`: выполняет список по порядку; ждёт завершения текущего действия, останавливается при failure.
- `selector`, `children`: пробует детей по убыванию `priority` (по умолчанию 0). Первый успешный/выполняющийся узел выбран. Более приоритетный доступный ребёнок прерывает старую ветку и сбрасывает её таймеры. При равном приоритете используется порядок JSON.
- `repeat`, `child`: после success или failure сбрасывает дочернюю ветку и повторяет её со следующего кадра.
- `wait`, `seconds`: таймер игрового времени.
- `condition`, `condition`: именованная проверка, возвращает success/failure.
- `action`, `action`: именованное действие со своим состоянием и статусом running/success/failure.

Первое дерево: ждать 1 с один раз → повторять приоритетную последовательность «игрок рядом → прыжок 0.6 с → ждать 0.5 с». При отсутствии игрока тень стоит; проверка возобновляется каждый кадр через selector. Низкоприоритетная ветка wait 0.1 задаёт спокойное ожидание. Начавшийся прыжок заканчивается даже при выходе игрока из радиуса.

`player-near`: одновременно проверяет разницу секций `sections:1`, горизонтальный радиус `radius:3.5` в единицах мира и вертикальную дистанцию `verticalRange:3`. Это не позволяет тени реагировать на игрока на далёком витке, оказавшемся рядом в проекции.

`jump.duration`: время прыжка. Высота берётся из существующего `stats.hopHeight`. На старте фиксируется текущая полоса игрока; прыжок смещает тень в её сторону в пределах той же платформы. Ожидание больше не включает старое постоянное слежение за полосой. Контакт, стомп и урон используют ту же высоту прыжка, что и изображение врага.

Новые действия и проверки добавляются в реестры `actions` / `conditions` модуля `src/enemy-behavior.js`; общий интерпретатор `src/state-tree.js` получает эти реестры без зависимости от Three.js. Обработчик действия получает `(context, dt, memory, node)`, где memory принадлежит отдельному узлу конкретного врага. В node доступны параметры из JSON. Возвращать нужно один из трёх статусов. Таймеры и состояние независимы у каждого врага; конфигурация не изменяется.

Таймеры дискретны по игровым кадрам; остаток dt не переносится на следующее действие. На паузе дерево не продвигается. Во время hurt таймеры заморожены. Мёртвые враги не обновляют дерево; сброс забега вызывает reset. Ошибки имён действий/условий и структуры обнаруживаются при загрузке.

Проверки: `node --test tests/state-tree.test.js tests/enemy-config.test.js tests/beast-knockback.test.js` — 12 тестов проходят. Production-сборка проходит.

## Общие действия монстров (ООП)

`src/monster.js`: базовый `Monster`, `EnemyAction`, общее действие `JumpAction`. Фабрика возвращает экземпляр Monster с визуальными частями и характеристиками. Каждый монстр, включая босса, имеет jump в actions; наличие действия не меняет автоматически сценарий босса или врагов без дерева.

Узел дерева: `{ "type":"action", "action":"jump", "params":{"height":0.8,"duration":0.6} }`.

Порядок параметров: значения по умолчанию действия / hopHeight монстра → params дерева → monster.modifyActionParameters(name, parameters) → проверка. Можно переопределить метод в подклассе или задать `stats.actionModifiers.jump.height` числом (замена) либо `{multiply:1.5,add:0.2}`. Параметры копируются и фиксируются на старте конкретного прыжка; дерево и соседние монстры не изменяются. Если height отсутствует, используется hopHeight.

Высота pose.height — в единицах мира; main использует её и для положения модели, и для контакта/стомпа/дэша. pose.leap остаётся нормализованной фазой для анимации. Исполнение действия хранит состояние в памяти отдельного узла дерева, а не в общем экземпляре JumpAction. Новые типы действий наследуются от EnemyAction и регистрируются в actions базового Monster либо его подкласса.
