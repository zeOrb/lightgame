# Рандом забега

По мотивам [RNJesus: RNG в Binding of Isaac](https://www.reddit.com/r/bindingofisaac/comments/3p5a03/rnjesus_an_introduction_on_how_rngs_are_used_and/).

У забега один сид. Игра записывает его в параметр seed адреса: ссылку можно скопировать и открыть снова. «Начать заново» повторяет этот забег, «Следующий забег» удаляет старый сид и генерирует новый. При одинаковых версии генерации, настройках этажей и изученных навыках повторяются структура и игровые случайности. Это не запись ввода или полное сохранение мира.

## Игровые потоки

src/random-manager.js: xorshift32 (13, 17, 5), версия 1. Нулевое состояние исключено. float возвращает [0,1), int(min,max) включает обе границы и использует отбрасывание неполного диапазона перед остатком от деления.

src/random-manager.js экспортирует randomManager. create(...path) создаёт независимую последовательность для конкретного объекта; stream(...path) возвращает сохраняемый поток событий. sample(...path) даёт стабильную выборку без продвижения других потоков. Пути кодируются массивами, а не склейкой строк с разделителями.

- layout / конфиг / ID этажа / категория: отверстия и размещение контента. Категории имеют отдельные потоки, но учитывают общие ограничения свободных мест. Для диапазонов количества резервируется минимум последующих категорий; фиксированные невозможные настройки дают ошибку.
- geometry / shelves / секция: одинаковая ширина видимой ступени и её коллизии.
- loot / ID этажа / секция: количество и тип исходных камней.
- chests / ID этажа / секция: содержимое каждого сундука независимо от порядка открытия.
- secret-layout / ID этажа: проходимая форма дороги и положение целей.
- secret-order / секция: последовательность секретной арены.
- enemies / индекс арены / boss-phase: игровая фаза босса.

snapshot()/restore() сохраняют и восстанавливают только RNG-состояние в JSON, с проверкой версии и сида. Для полного продолжения игры понадобится отдельно сохранить состояние мира и игрока. reset() возвращает потоки к началу при повторе забега. Изменение алгоритма или схемы путей требует поднять RNG_VERSION и обновить проверки воспроизводимости.

## Графика

Партиклы, звук, текстуры, декоративная трава и лианы используют обычный Math.random, централизованный в RandomManager.graphics(), через существующие совместимые функции createVisualRandom/visualSample или напрямую. У них нет сида и сериализации. Параметры плавных анимаций выбираются один раз на объект, чтобы новая выборка каждый кадр не создавала дрожание.
