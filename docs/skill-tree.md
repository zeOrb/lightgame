# Редактирование древа навыков

Основной файл: `src/skill-tree.json`. В нём находятся ветки, названия, описания, цены, зависимости, символы и эффекты всех навыков.

## Расположение

- Переставьте объекты в массиве `branches`, чтобы переставить ветки вокруг солнца.
- Переставьте объекты в `nodes`, чтобы изменить расстояние нод от центра: первая ближе всего, последняя дальше всего.
- Можно добавлять ветки и удлинять существующие. Размер карты и число нод в карточках вычисляются автоматически.
- `requires` задаёт открытие навыка независимо от его места на экране. У существующих нод это поле заполнено явно: перестановка не изменит связи. Чтобы изменить цепочку, поменяйте `requires`.
- Если у новой ноды не указать `requires`, она привяжется к предыдущей в своём массиве. `"requires": null` открывает ноду сразу от центрального солнца. Можно ссылаться и на другую ветку. Циклы запрещены.

**Не меняйте `id` существующих навыков:** по нему сохраняется изучение. При перестановке нод уже купленные навыки и очки сохраняются. Для нового навыка придумайте новый уникальный ID.

## Добавление ноды

Вставьте такой объект в `nodes` нужной ветки:

```json
{
  "id": "heart3",
  "name": "Сердце рассвета",
  "description": "Ещё +25 максимального HP.",
  "cost": 2,
  "requires": "heart2",
  "icon": 0,
  "effects": {
    "maxHP": { "add": 25 }
  }
}
```

`cost` — целое число от 0; по умолчанию 1. `icon` — номер одного из пяти пиксельных символов (0–4); если не указать, символ выбирается автоматически. Описание редактируется вручную и не вычисляется из эффектов.

Новая ветка — объект с уникальным `id`, названием `name` и непустым массивом `nodes` в `branches`.

## Эффекты

В `effects` используйте имена параметров из `baseStats`. Для каждого параметра укажите одну операцию:

| Операция | Пример | Результат |
| --- | --- | --- |
| `add` | `"maxHP": { "add": 25 }` | Прибавить 25 HP |
| `multiply` | `"speed": { "multiply": 1.15 }` | Увеличить скорость на 15% |
| `set` | `"doubleJump": { "set": true }` | Включить двойной прыжок |

Одна нода может менять несколько параметров. Эффекты суммируются с эффектами остальных изученных нод. Зависимость применяется раньше дочернего навыка; перестановка в JSON не меняет порядок расчёта. Для флагов используйте только `set` с `true`/`false`.

| Параметры | Что меняют |
| --- | --- |
| `maxHP`, `drainScale`, `damageScale` | Максимальный свет, множители пассивного расхода и урона |
| `speed`, `jump`, `doubleJump`, `potionScale` | Движение, прыжки, длительность эффектов склянок |
| `phaseCooldown`, `phaseDistance` | Множители перезарядки и длины дэша |
| `phaseHeal`, `resonance`, `flare` | HP за убийство дэшем, сокращение кулдауна, способность E |
| `shardHeal`, `magnet`, `regen` | Лечение осколка, радиус подбора, множитель лечения в лучах |
| `rayEntryHeal`, `rayDashHeal` | HP за первый вход / первый дэш в каждом луче за забег; ненулевой `rayEntryHeal` заменяет постоянное лечение |
| `extraFloors`, `glintSpacing`, `lastLight` | Дополнительные этажи, шаг появления осколков, спасение при исчерпании света |

`baseStats` — параметры без улучшений. Через JSON можно создавать новые комбинации существующих эффектов. Для принципиально новой механики сначала нужна реализация в JavaScript.

## Проверка

После правки обновите страницу: параметры текущего забега берутся при загрузке. `npm run build` проверяет сборку; `npm test` — поведение игры. Загрузчик сообщает об ошибках с указанием ноды: повторяющиеся ID, неверная цена/операция/тип, неизвестный параметр, отсутствующая зависимость или цикл.

Файл JSON включается в сборку Vite и работает на GitHub Pages без дополнительных запросов или сервера.
