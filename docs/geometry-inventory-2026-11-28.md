Это список семейств, а не каталог каждого индивидуального составного ассета. Например, сундуки вместе состоят из 49 Mesh; одно число для всего сундука нельзя подменять числом одного дочернего Mesh. Лестницы состоят из 567 Mesh; фоновые пропсы — из 906 батчей/мешей, содержащих 9803 экземпляра отдельных деталей.

Крупные отдельные геометрии в снимке: объединённый библиотечный меш — до 24 576 треугольников, меш секретной дороги/комнаты — до 13 644, меш угрозы — до 12 600, лестничный меш — до 3824. Это именно отдельные меши; составной объект может содержать несколько таких мешей.

Ранее измеренные примерно 1.4 млн треугольников **за кадр** — другая метрика: видимые меши после отсечения, с повторной отрисовкой в нескольких проходах. Их нельзя напрямую сравнивать с 2.27 млн геометрии всей башни. Инстансирование сокращает draw calls и хранение общей геометрии, но GPU всё равно обрабатывает треугольники каждого экземпляра.

Основной геометрический бюджет: лестницы (~37%), библиотека (~17%), подлестничные детали (~11%), секретные зоны (~11%) и фоновые пропсы (~10%). Они суммарно дают около 86% треугольников. Камни и туман почти не влияют на число треугольников, хотя туман может быть дорогим по пикселям и шейдеру.

Повторный снимок: открыть игру с `?geometry-report=1`, JSON находится в script#geometry-report. Счётчик реализован в src/geometry-inventory.js; обычный запуск его не загружает.
