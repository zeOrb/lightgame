# Аура объектов

Общий модуль: `src/object-aura.js`. Подходит для любого `THREE.Object3D`: сундука, предмета, врага, декора или группы моделей.

В конфиге типа объекта используется блок `visuals.aura`. Владелец модели передаёт `visuals` в `setObjectAura(object, visuals)` при создании или изменении настроек. Отсутствие блока или `enabled: false` означает отсутствие эффекта. Модуль не зависит от игрового цикла, инпута и конкретного типа объекта.

| Параметр | Значение по умолчанию | Назначение |
| --- | --- | --- |
| enabled | false | Включение |
| color | #ffffff | Цвет |
| opacity | 0.75 | Интенсивность, 0–1 |
| offset | [0, 0, 0] | Локальное смещение |
| scale | [1, 1, 1] | Размер в локальных координатах |
| blend | additive | Сложение света; также поддерживается normal |
| depthTest | true | Перекрытие геометрией сцены |

Повторный вызов обновляет существующую ауру. Выключение удаляет спрайт и освобождает его материал. Мягкая текстура общая, материалы независимы: изменение одного объекта не меняет другие. Аура следует трансформации и видимости владельца. Коллизии и материалы модели не затрагиваются. Это визуальный ореол, а не источник освещения окружающих поверхностей.

## Сохранённый внешний вид

У сундуков в `src/interactables.json` явно записаны прежние параметры: белый цвет, opacity 0.75, offset [0, 0.48, 0], scale [2.1, 2.3, 1], additive, depthTest true. Пиксели текстуры и настройки рендера сохранены. Остальным существующим объектам эффект автоматически не добавляется. Их собственные эффекты свечения не изменяются.
