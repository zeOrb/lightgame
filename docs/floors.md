# Этажи башни

Рабочий файл: `src/floors.json`. Полный пример с ручным и генерируемым ярусом: `examples/floors.mixed.json` (можно скопировать поверх рабочего JSON).

`floors` перечисляется **сверху вниз, по порядку прохождения**. `id` — стабильное имя яруса, а не отображаемый номер этажа. `baseFloors` — количество обычных ярусов; улучшения добавляют ярусы после них. Меняя порядок, переставляйте целые объекты в `floors`.

## Два режима, независимо для каждой категории

Каждый этаж наследует `defaults`. В объекте этажа достаточно указать изменяемые поля. Например, ручные ступени и окна можно сочетать с генерируемыми врагами и лутом.

- `mode: "generated"`: `count` — точное количество или диапазон `[минимум, максимум]`. Места выбираются по `seed` и `id` яруса. Одинаковые настройки дают одинаковую расстановку. Измените `seed`, чтобы пересобрать план. Косметическая случайность отдельно от этого сида.
- `mode: "explicit"`: `items` — точный список. Пустой список отключает категорию. `offset` — номер секции внутри этого этажа, начиная с **0**, до `steps.count - 1`.

Ручные места резервируются до генерации. Генератор не размещает объекты в провалах, на последней ступени с воротами или поверх других занятых мест. Если запрошенное количество не помещается, загрузка выдаст ошибку с id этажа и категорией. Ручные витражи нельзя совмещать с тенями, врагами, книгами и угрозами.

## Ступени

`steps.count` — число секций (4–128). Все следующие этажи, ворота и арены получают новые границы автоматически. Секция по-прежнему поворачивает маршрут на π/14 и опускает его на 0.5 м; увеличение количества делает ярус длиннее и выше по вертикальному диапазону.

В генерации `steps.holes.count` задаёт число дыр, `safeStart` и `safeEnd` — сколько секций у концов оставить целыми. `styles: ["carved", "plain"]` чередует резные и простые деревянные ступени. `decorations: false` убирает предметы декора с них. `innerRadius` задаёт внутренний радиус ступени и учитывается коллизией; значение должно быть меньше внешнего радиуса 17 м.

В ручном режиме `steps.items` перечисляет существующие ступени: `[0, 1, {"offset": 2, "style": "plain", "decorations": false}, 4, 5, ...]`. Неперечисленные секции становятся провалами. Последняя секция обязательна: на ней ворота. Настройки отдельной ступени перекрывают настройки яруса.

## Содержимое

- `windows`: число окон. В ручном режиме: `{"offset": 3, "width": 2.3, "height": 5.8, "heightAboveShelf": 4}`. Проекция и лечебная зона привязываются к этой секции. `angleDegrees` при необходимости задаёт угол окна вокруг башни.
- `loot`: число мест с камнями. `gemsPerTile: null` и `pool: null` используют улучшения текущего забега. Иначе задайте лимит камней и пул id из `collectibles.json`. Ручной предмет: `{"offset": 4, "id": "ruby", "count": 2}` — ровно два рубина. `lane` опционален (от -1.2 до 1.2 м).
- `enemies`: число врагов и `pool` из id в `enemies.json`. Ручной: `{"offset": 7, "id": "cat", "lane": 0}`.
- `threats`: число угроз и `pool`: `moving-platform`, `pendulum`, `ink-wave`, `thorns`. Ручной: `{"offset": 9, "id": "pendulum", "lane": 0, "phase": 0.3}`. Дыры задаются через `steps`.
- `shadows`, `chests`, `bottles`, `books`, `springboards`: те же `mode/count/items`. Для простого ручного размещения достаточно `items: [3, 8]`.
- `secret`: `enabled` и `offset` входа на секретную дорожку. Её дорога и комната входят в корень исходного этажа.
- `arena`: `enabled` и `boss` из `enemies.json`. По умолчанию включена на десятом ярусе.
- `lighting.daylight`: `null` сохраняет общий градиент башни; число 0–1 задаёт яркость окружения этого яруса.

Для дополнительных этажей от навыков `extraFloor.arena.every` задаёт период босса, `extraFloor.secret.every` — период секретки.

## Корни и поворот

Иерархия Three.js: `TowerRoot → FloorRoot:<id> → объекты яруса`. Полки, окна, книги библиотеки, лут, сундуки, угрозы, лианы, секретки и арены сгруппированы по ярусам. Общие стены и колонны находятся в `TowerRoot`. Мировые VFX и игрок остаются управляемыми игровыми системами.

В JSON:

- `tower.rotationYDegrees` — поворот башни целиком;
- `floors[i].rotationYDegrees` — дополнительный поворот яруса относительно башни.

Поддержан **поворот вокруг вертикальной оси Y**. Наклон X/Z и перенос ярусов этим API не поддерживаются: гравитация, горизонтальная поверхность арены и высоты этажей остаются вертикальными.

В коде доступен `scene.userData.tower`:

```js
const tower = scene.userData.tower;
tower.rotateFloor('arrival', 20); // абсолютный локальный угол в градусах
tower.rotateTower(45);
// Либо tower.floors[index].rotation.y = уголВРадианах;
// tower.sync() вызывается в игровом цикле.
```

Поворот меняет маршрут и положение объектов, обновляет витражные проекции и опоры секретной дороги. Независимые повороты соседних этажей могут разъединить их проходы: подбирайте углы как часть дизайна уровня. Это не автоматический механизм стыковки этажей.
